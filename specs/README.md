## Arbeidsregel

1. **Spec først** — ny feature eller endring beskrives i relevant spec-fil.
2. **Kode etterpå** — implementer mot spec, ikke omvendt.
3. **Hold sync** — hvis koden avviker med vilje, oppdater spec i samme PR/commit-runde.
4. **Agent/AI** — se [AGENTS.md](../AGENTS.md) og `.cursor/rules/spec-driven.mdc`.
