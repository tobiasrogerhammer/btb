# nextround logopakke

Speil av `nextround-logopakke.zip`. Kanoniske filer appen bruker:

| Bruk | Fil |
|------|-----|
| Nav (wordmark) | `/nextround-logo-white.png` |
| Merke / delebilde | `/logo.png` |
| OG | `/og-image.png` |
| Favicon / app-ikon | `app/favicon.*`, `app/icon.*`, `app/apple-icon.*` |

Varianter (hvit/svart/oransje/stående) ligger i undermappene her.
